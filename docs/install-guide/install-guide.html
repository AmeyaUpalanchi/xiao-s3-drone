XIAO S3 Drone Install Guide

Put the firmware on the drone, then fly it from an Android phone or an iPhone

The Drone Community
Firmware 1.2.3 · App 1.2.2 · Nov 2026

!Safety first

  1. Never connect USB and the battery at the same time. The battery feeds the USB power line on these boards: the pack gets charged from the computer and the USB port can shut down. Flash on USB only, fly on the battery only.
  2. Props off for flashing, the motor test and any bench test.
  3. On the iOS build the props are live whenever an app is connected. It arms itself, so raising the throttle spins the motors straight away.
  4. First flights low and over a soft surface, everyone standing behind the pilot.

1Which files to use

Pick the firmware by the phone that flies the drone. The drone reports its build as fw 1.2.3-tdc or fw 1.2.3-tdc-ios.

2Flash over USB

A new drone needs one USB flash; after that it updates over Wi-Fi. You need Python 3 and a USB-C data cable (some only charge).

Mac or Linux

  1. Unzip the firmware and open a terminal in that folder.
  2. Unplug the battery, then plug in the XIAO.
  3. Run ./flash-mac-linux.sh. It finds the port and installs esptool if missing.
  4. Wait for Done. (about 15 s).

Windows

  1. Unzip the firmware, unplug the battery, plug in the XIAO.
  2. Device Manager > Ports: note the COM number, e.g. COM5.
  3. In that folder run flash-windows.bat COM5 and wait for Done.

By hand, any system

python3 -m pip install esptool
python3 -m esptool --chip esp32s3 -p <port> -b 460800 write_flash 0x0 TheDroneCommunity-firmware-1.2.3-full.bin

Use the -ios file name for the iOS build.

XIAO not found? Hold B (BOOT) while plugging in the cable, then run it again.

Check: unplug USB, connect the battery, wait 5 s. Wi-Fi ESP-DRONE_ + 12 characters appears, password 12345678.

Flashing a batch

Swap XIAOs and re-run the script, about 15 s each. esptool prints MAC: 7c:e8:b1:a6:94:4c; the drone's Wi-Fi is that MAC in capitals with the last byte plus one: ESP-DRONE_7CE8B1A6944D. Write it on the frame.

3Update over Wi-Fi

Any drone already on our firmware (1.1.0 or later) updates from the Android app, no cable.

  1. Copy ESPDrone-1.2.3-update.bin (or the -ios one) to the phone.
  2. Charge the battery, power the drone from it, put it on the ground.
  3. Join the drone's Wi-Fi and tap Connect in the app. Don't arm.
  4. Gear > Drone settings > Firmware update > Choose firmware file…
  5. Wait while it shows Sending …%. The drone reboots by itself.
  6. Reconnect: Installed: shows the new version.

Works on the iOS build too: it disarms for the update while it sits on the ground with the throttle at zero, and waits 15 s before arming itself again.

Which version is on a drone?

Drone settings > Firmware update shows Installed:. Over USB the boot log prints drone API … (fw 1.2.3-tdc).

Needs updating

Drones on 1.2.2 or older spin steadily in flight (yaw fix is in 1.2.3) and may refuse clone IMU chips (fixed in 1.2.2). Update every drone before flying it.

Rename a drone's Wi-Fi

With many drones in one room: Drone settings > Wi-Fi name and password, type a short name (it becomes ESP-DRONE_<name>) and a new password, then Save and restart drone. Anyone else flying it enters the same password there before Connect.

Connect · Fly · Fix

Android app, iPhone app, the checks before the first flight, and what to do when it misbehaves

The Drone Community
XIAO S3 Drone · Install Guide

4Android appAndroid 8+

Install

  1. Copy TheDroneCommunity-1.2.2.apk to the phone.
  2. Tap it; allow Install unknown apps if asked; tap Install or Update.

Connect

  1. Battery in, USB out.
  2. Wi-Fi: join ESP-DRONE_…, password 12345678. On No internet, tap Stay connected.
  3. Turn mobile data off.
  4. Tap Connect, wait for Parameters TOC fetch finished. Arm lights up after it.

Fly

  1. Left stick down, tap Arm, raise it within 20 s.
  2. Left stick: throttle and turn. Right stick: tilt.
  3. Land brings it down. Hold to stop cuts the motors (it drops).

After every battery swap or USB plug-in the drone restarts: tap Disconnect, Connect, then Arm again.

5iPhone and iPadiOS build

iPhones use Espressif's free ESP-Drone app (App Store, iOS 10+) with the 1.2.3-ios firmware.

Prepare the drone, once

  1. Flash …-1.2.3-ios-full.bin over USB, or send ESPDrone-1.2.3-ios-update.bin from the Android app.

Connect

  1. Install ESP-Drone by Espressif Systems.
  2. Battery in, USB out.
  3. Settings > Wi-Fi: join ESP-DRONE_…, password 12345678. Stay on it if iOS warns about no internet.
  4. Open ESP-Drone and connect.

Fly

  1. Throttle at the bottom for 1 s: the drone arms itself (no Arm button).
  2. Raise the throttle: the motors spin straight away.
  3. Throttle to the bottom to stop. It disarms after 20 s idle on the ground or 2 s after the app disconnects.

Link lost in the air or battery low: it lands by itself. Not yet test-flown with this app: try one drone first.

6Before the first flightonce per drone · Android app

MotorPositionPinSpins / prop
M1Front rightD3 · GPIO 4CW
M2Rear rightD7 · GPIO 44CCW
M3Rear leftD2 · GPIO 3CW
M4Front leftD0 · GPIO 1CCW
  • Props match the table. Firmware 1.2.3 expects M1 + M3 CW, M2 + M4 CCW.
  • Motor test, props off: Drone settings > Motor test > Test all four in turn.
  • Level calibration: flat table, hands off, Drone settings > Level calibration > Calibrate.
  • First hover: 30 cm for 5 s. It holds its heading; a tap of yaw right turns the nose right.

Spins steadily on take-off? Land at once: a motor or prop is the wrong way round for this table.
